# 1~3단계 학습 노트 (Claude 작성, 검토용)

> 이 노트는 Claude가 썼다. 읽고 나서 각 단계의 완료 기준을 **AI 없이** 직접 통과했는지 확인하고, 막히는 곳은 질문으로 남긴다.
> 식 번호·절 번호는 `papers/ho2020_ddpm.pdf`(Ho et al., 2020, arXiv 2006.11239) 기준. 원문과 대조할 것.

## 1단계. 직관

**비유 (출발점용):** 잉크 한 방울을 물에 떨어뜨리면 조금씩 퍼져 결국 균일한 색이 된다(forward). 이 과정을 거꾸로 돌리는 법을 배우면, 균일한 물에서 잉크 방울 모양을 되살릴 수 있다(reverse). 단, 거꾸로 가는 한 걸음 한 걸음은 아주 작아서 "조금 덜 퍼진 상태"만 맞히면 된다.

**비유 없이:**
- **Forward 과정 q:** 데이터 x_0에 작은 가우시안 노이즈를 T번(=1000) 조금씩 더해 x_T를 거의 순수한 표준정규 노이즈로 만든다. 학습할 파라미터가 없고 정해진 스케줄 β_t만 따른다. (2절, 식 2)
- **Reverse 과정 p_θ:** 순수 노이즈 x_T에서 시작해 한 단계씩 노이즈를 걷어내 x_0을 만든다. 각 단계는 가우시안 p_θ(x_{t-1}|x_t)이고 그 평균을 신경망이 예측한다. (2절, 식 1)
- **학습:** 실제로 신경망은 "x_t에 섞여 있는 노이즈 ε가 무엇이었는지"를 맞히도록 학습된다. 노이즈를 알면 한 단계 되돌리는 평균을 계산할 수 있다. (3.2절)

**완료 기준 자가 점검:** 위 내용을 보지 않고 forward / reverse / 학습을 각각 한 문장으로 말해 본다.

## 2단계. 수식

표기: α_t = 1 − β_t, ᾱ_t = ∏_{s=1}^{t} α_s. 스케줄은 β_1 = 10⁻⁴ … β_T = 0.02 선형, T = 1000 (4절).

### 2-1. q(x_t | x_0)의 닫힌 형태 (식 4)

| 줄 | 식 | 쓴 성질 |
|---|---|---|
| 1 | q(x_t\|x_{t-1}) = N(√α_t · x_{t-1}, (1−α_t) I) | 정의 (식 2) |
| 2 | x_t = √α_t · x_{t-1} + √(1−α_t) · ε_{t-1}, ε ~ N(0, I) | 재매개변수화: N(μ, σ²) = μ + σε |
| 3 | x_{t-1} = √α_{t-1} · x_{t-2} + √(1−α_{t-1}) · ε_{t-2} 대입 → x_t = √(α_tα_{t-1}) · x_{t-2} + √α_t√(1−α_{t-1}) · ε_{t-2} + √(1−α_t) · ε_{t-1} | 줄 2를 한 번 더 적용 |
| 4 | 노이즈 두 항의 분산 합: α_t(1−α_{t-1}) + (1−α_t) = 1 − α_tα_{t-1} | 독립 가우시안의 합은 가우시안, 분산은 더해진다 |
| 5 | x_t = √(α_tα_{t-1}) · x_{t-2} + √(1−α_tα_{t-1}) · ε̄ | 줄 4 |
| 6 | 귀납적으로 반복 → **x_t = √ᾱ_t · x_0 + √(1−ᾱ_t) · ε** | 수학적 귀납법 |

의미: 아무 t의 x_t를 한 번에 샘플링할 수 있다 → 학습 때 t를 무작위로 뽑아 바로 학습 가능 (Algorithm 1).
코드: `ddpm/diffusion.py`의 `q_sample`. 결과 표 `runs/forward/schedule.txt` (t=401에서 신호 0.44, t=1000에서 0.006).

### 2-2. 사후분포 q(x_{t-1} | x_t, x_0) (식 6, 7)

x_0을 알면 한 단계 되돌리는 분포도 가우시안으로 닫혀 있다:
- 평균 μ̃_t = [√ᾱ_{t-1} β_t / (1−ᾱ_t)] · x_0 + [√α_t (1−ᾱ_{t-1}) / (1−ᾱ_t)] · x_t
- 분산 β̃_t = [(1−ᾱ_{t-1}) / (1−ᾱ_t)] · β_t

(베이즈 정리 + 가우시안끼리 곱하면 가우시안. 유도는 노트에 직접 써 볼 것 — 지수의 x_{t-1}에 대한 2차식을 완전제곱.)

### 2-3. 목적함수: ELBO → L_simple

| 단계 | 내용 | 위치 |
|---|---|---|
| a | 음의 로그우도의 상한(변분 하한) L | 식 3 |
| b | L = L_T + Σ_{t>1} L_{t-1} + L_0, 각 L_{t-1} = KL(q(x_{t-1}\|x_t,x_0) ‖ p_θ(x_{t-1}\|x_t)) | 식 5 |
| c | 분산을 σ_t²로 고정하면 두 가우시안의 KL → 평균 차이의 제곱: L_{t-1} = E[ ‖μ̃_t − μ_θ‖² / (2σ_t²) ] + C | 식 8 |
| d | x_0 = (x_t − √(1−ᾱ_t) ε) / √ᾱ_t 를 μ̃_t에 대입하고, 같은 꼴로 μ_θ = (1/√α_t)(x_t − β_t/√(1−ᾱ_t) · ε_θ(x_t, t)) 로 둔다 | 식 10, 11 |
| e | 그러면 L_{t-1} ∝ ‖ε − ε_θ(√ᾱ_t x_0 + √(1−ᾱ_t) ε, t)‖² (앞에 t별 가중치) | 식 12 |
| f | **가중치를 버린 것이 L_simple = E_{t,x_0,ε} ‖ε − ε_θ(x_t, t)‖²** | 식 14 |

L_simple의 의미 (3.4절): 원래 가중치보다 작은 t(노이즈 적은, 쉬운 단계)의 비중을 줄이고 큰 t(어려운 단계)에 집중하게 되어 샘플 품질이 더 좋았다. 대신 엄밀한 로그우도 최적화는 아니다(표 2: NLL은 더 나쁨).
코드: `Diffusion.loss`.

### 2-4. 샘플링 (Algorithm 2)

x_{t-1} = (1/√α_t)(x_t − β_t/√(1−ᾱ_t) · ε_θ(x_t, t)) + σ_t z, 마지막 단계(t=1)에서는 z = 0.
σ_t² = β_t 와 σ_t² = β̃_t 두 선택 모두 비슷한 결과 (3.2절). 이 구현은 β_t.
코드: `Diffusion.p_sample`, `Diffusion.sample`.

**완료 기준 자가 점검:** 2-1의 여섯 줄을 빈 종이에 혼자 다시 쓴다.

## 3단계. 점검용 질문 (답을 내 말로 쓰고, 틀린 것만 지적 요청)

1. forward 과정에 학습 파라미터가 없는 이유는?
2. q(x_t|x_0)이 닫힌 형태라서 학습에서 무엇이 가능해지는가?
3. 신경망이 x_{t-1}이나 x_0 대신 ε을 예측하게 한 이유는? (3.2절, 표 2)
4. L_simple에서 t별 가중치를 버리면 무엇이 달라지는가?
5. 샘플링 마지막 단계에서 노이즈 z를 더하지 않는 이유는?
6. 왜 T를 1000처럼 크게 잡는가? (각 단계가 작아야 reverse도 가우시안으로 근사 가능)
7. 이 코드에서 t는 0~999, 논문에서는 1~1000이다. 어디서 어긋날 수 있는가?
