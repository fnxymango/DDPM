# 6단계: PneumoniaMNIST 생성 결과 평가

> Claude 초안. 방법 선택과 해석은 가이드라인상 직접 판단할 부분이므로 검토·수정 필요 (직접해야함).
> 수치 출처: `runs/pneumonia/eval_ema_step005000/eval.json`, `runs/pneumonia/eval_ema_step020000/eval.json`

## 1. 설정

- 데이터: PneumoniaMNIST 28×28 흑백, 학습 4,708장 (폐렴 74.2%), test 624장 (폐렴 62.5%)
- 모델: MNIST와 같은 코드·하이퍼파라미터 (U-Net 11.25M, T=1000, 선형 β 1e-4~0.02, L_simple, EMA 0.9995), 조건 없음(라벨 미사용), 데이터 증강 없음
- 학습: 20,000스텝, 배치 128 (약 544에폭), 최종 loss 0.0216
- 평가: 5k스텝과 20k스텝 체크포인트(EMA)에서 각각 1,000장 생성, test 영상과 비교

## 2. 고른 방법과 이유

| 방법 | 역할 | 고른 이유 |
|---|---|---|
| 최근접 학습 영상 비교 (픽셀 공간) | 주 평가 | 학습 데이터가 4,708장으로 작아 외우기가 가장 큰 위험. 논문도 과적합이 아님을 보이려고 같은 방법을 씀(5.2절, 부록 D 그림 12·15) |
| 분류기 기반 평가 | 보조 | "정상·폐렴 특징을 담았나"에 접근하는 유일한 방법 |
| 밝기 히스토그램 | 보조 | 계산이 간단하고, 전체 밝기·대비가 실제와 맞는지 상태 점검 |
| FID | 제외 | Inception-v3는 컬러 자연 영상으로 학습되어 28×28 흑백 X선과 영역이 다름. 1,000장으로는 논문(5만 장)과 비교 불가 |

최근접 비교의 기준값: test 영상(학습에 안 쓴 실제 영상)이 학습 영상과 얼마나 가까운지를 "새 영상이 원래 가지는 거리"로 보고, 생성 영상의 거리와 비교했다. 거리는 [0,1] 스케일의 픽셀당 RMS.

| 지표 | 실제 test | 5k스텝 | 20k스텝 |
|---|---|---|---|
| 영상별 평균 밝기 (평균) | 0.564 | 0.442 | 0.570 |
| 영상별 밝기 표준편차 (평균) | 0.150 | 0.140 | 0.147 |
| 최근접 학습 영상 거리, 중앙값 | 0.153 | 0.147 | 0.144 |
| 최근접 학습 영상 거리, 최솟값 | 0.086 | 0.089 | 0.074 |
| test 하위 1% 거리보다 가까운 비율 | 1% (정의상) | 0.3% | 2.7% |

## 4. 해석 (직접해야함)

**생김새.** 20k스텝 생성 영상은 쇄골, 늑골 윤곽, 종격동, 좌우 폐야가 있는 흉부 X선 구도를 갖췄다. 실제 영상보다 질감이 매끈하고 폐 안의 세부 음영이 적으며, 일부(5장 중 2장)는 전체가 뿌옇다.

**밝기.** 5k스텝에서는 생성 영상이 실제보다 어두웠다(0.442 vs 0.564). 20k스텝에서는 평균 밝기와 대비 분포가 실제와 거의 겹친다. 전체 밝기 분포를 맞추는 데는 5k스텝으로 부족했다.

**외우기.** 생성 영상 대부분은 학습 영상과의 거리가 test 영상과 비슷한 범위에 있다(중앙값 0.144 vs 0.153). 그러나 학습을 오래 할수록 학습 영상에 아주 가까운 샘플이 늘었다(0.3% → 2.7%, 기준 1%). 20k스텝의 최솟값(0.074)은 test 영상의 최솟값(0.086)보다 작다. 가장 가까운 8쌍을 보면 똑같이 복사한 영상은 아니고, 디테일이 적고 흐린 영상끼리 가까웠다. 따라서 통째로 복사한 증거는 없지만, 작은 데이터에서 학습을 길게 하면 학습 영상에 가까워지는 경향이 있다.

**정상·폐렴.** 20k스텝 생성 영상의 폐렴 판정 비율(67.8%)은 실제 데이터와 같은 범위에 있다. 그러나 분류기가 test에서 폐렴을 8.3%p 과대 판정하므로, 이 숫자로 생성 영상의 실제 정상·폐렴 비율을 추정할 수는 없다. 분류기 확신도가 생성 영상에서 오히려 높은 것(0.961 vs 0.939)은, 생성 영상이 실제보다 단순해서 애매한 경우가 적기 때문일 수 있다. 확신도가 높다고 해서 폐렴 소견이 임상적으로 맞다는 뜻은 아니다.

**종합.** 같은 DDPM 코드가 의료 영상에서도 흉부 X선 형태와 밝기 분포를 재현했다. 그러나 세부 질감은 부족하고, 작은 데이터에서 학습을 오래 할수록 외우기 경향이 커졌으며, 생성 영상이 실제 병변 특징을 담았는지는 확인하지 못했다.

## 5. 한계

- 28×28 해상도라 폐렴 소견(경화, 침윤)을 표현하거나 판단하기 어렵다.
- 최근접 비교를 픽셀 공간에서만 했다. 조금 이동하거나 밝기만 다른 복제는 놓칠 수 있다(논문은 특징 공간도 사용).
- 분류기가 폐렴 쪽으로 치우쳐 있고, 같은 데이터로 학습한 작은 CNN이라 평가자로서 독립적이지 않다.
- FID를 쓰지 않아 논문과 같은 지표로 비교할 수 없다.
- 시드 1개, 체크포인트 2개만 평가했다.
- 조건 없는 생성이라 정상·폐렴을 골라 생성할 수 없다.
- 전문가 판독이 없다.
